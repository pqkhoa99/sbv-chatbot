# Image Assets Required

Please add the following image files to `/frontend/public/images/`:

1. **sbv-logo.jpg** - Logo of Ngân hàng Nhà nước Việt Nam (State Bank of Vietnam)
   - Recommended size: 200x200px or larger
   - Should be a square or near-square logo
   - Will be displayed at 40x40px in header and 80x80px in welcome screen

2. **background-login.png** - Background image for login page
   - Recommended size: 1920x1080px or larger
   - Should be professional and related to banking/finance
   - Will be overlaid with a purple gradient (rgba(102, 126, 234, 0.8) to rgba(118, 75, 162, 0.8))

3. **background-chat.jpg** - Background image for chat page
   - Recommended size: 1920x1080px or larger
   - Should be subtle and professional
   - Will be overlaid with a white semi-transparent layer (rgba(255, 255, 255, 0.92))

## How to Add:

```bash
# Place images in this directory:
/Users/pqkhoa99/Documents/Master/251/sbv-chatbot/frontend/public/images/

# The images will be accessible at:
# - /images/sbv-logo.jpg
# - /images/background-login.png
# - /images/background-chat.jpg
```

Until you add these images, you may see broken image placeholders in the UI.
